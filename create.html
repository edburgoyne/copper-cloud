READY FOR THE WEB

A game that travels.

Copper Cloud uses Pygbag to run Pygame in a browser. Your game needs a main.py entry point, an asynchronous loop that yields every frame, and browser-compatible assets and dependencies.

Keep files your game needs in its assets/ folder, use relative paths, and test the compiled game in a browser. The guide walks through the actual project structure and checks.
